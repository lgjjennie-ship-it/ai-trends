## [OpenSSL Buffer Overflow in EVP\_EncodeBlock\(\) \(CVE-2026-121481, CVSS 9.8\)](https://github.com/openssl/openssl/pull/33652) ⭐️ 8.0/10

A critical buffer overflow vulnerability has been announced in OpenSSL&\#x27;s EVP\_EncodeBlock\(\) function, which is used for base64 encoding, with a high CVSS score indicating severe severity. This vulnerability is significant because it affects a widely used library, OpenSSL, which is critical for secure communications on the internet, potentially impacting many software products and services. The vulnerability occurs when EVP\_EncodeBlock\(\) is provided with input larger than ~1.5GB, leading to a buffer overflow. Exploitability depends on how untrusted input can reach the function.

**Background**: OpenSSL is a widely used open-source library for secure communications, providing cryptographic functions including base64 encoding. Buffer overflow vulnerabilities occur when a program writes more data to a buffer than it can hold, potentially causing system crashes or data corruption.
