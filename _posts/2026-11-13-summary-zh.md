## [Brave 搜索 API 支持通过 x402 协议的代理支付](https://brave.com/blog/search-api-agentic-payments/) ⭐️ 8.0/10

Brave 搜索 API 现在支持使用 x402 协议的代理支付，允许 AI 代理代表用户进行支付，无需逐个获得人类批准。 这一发展可能通过 AI 驱动的支付显著影响搜索引擎的收益模式，可能改变搜索服务的资金来源和消费方式。 x402 协议促进数字服务的即时、低成本支付，特别设计用于 API 货币化和代理商业，但其当前采用和有效性仍在评估中。

hackernews · sjdh76 · 11月13日 03:08 · [社区讨论](https://news.ycombinator.com/item?id=50477649)

**背景**: 代理支付涉及 AI 代理在用户设定的预定义限制内进行交易，通常用于零售或订阅服务。x402 协议是一个基于 HTTP 的支付系统，能够为 API 访问和数字服务进行自动支付。
