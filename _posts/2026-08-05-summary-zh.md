## [比较 Zigbee、Matter 和 Thread 物联网协议](https://arxiv.org/abs/2603.04221) ⭐️ 8.0/10

一项研究比较了 Zigbee、Matter 和 Thread 协议，揭示了它们之间的性能差异和潜在应用场景。 这项比较对物联网开发者和用户具有重要意义，因为它有助于他们根据需求选择合适的协议，从而影响设备兼容性和网络效率。 研究表明，OpenThread 的消息吞吐量比 Zigbee 扩展得更好，而 Zigbee 在早期就遇到了瓶颈，并且从节点掉线中恢复得比 OpenThread 更快。

hackernews · teleforce · 8月5日 00:10 · [社区讨论](https://news.ycombinator.com/item?id=49176983)

**背景**: Zigbee、Matter 和 Thread 是物联网中的关键协议，其中 Zigbee 基于 IEEE 802.15.4 用于低功耗应用，Matter 是一个用于无缝设备集成的开源标准，而 Thread 使用 6LoWPAN 在低功耗链路上传输 IPv6 数据包。

## [WebKit IP 和 DNS 泄漏影响代理浏览器和 iCloud 私人中继](https://mysk.blog/2026/08/04/webkit-proxy-icloud-private-relay-ip-leak/) ⭐️ 8.0/10

WebKit 的 IP 和 DNS 泄漏已被发现，影响了代理浏览器和 iCloud 私人中继，通过暴露用户的真实 IP 地址和 DNS 信息。 这些泄漏引发了严重的隐私和安全问题，因为它们可能允许第三方跟踪用户的在线活动并损害他们的匿名性。 当 WebKit 未能正确地将 DNS 请求通过 VPN 或代理路由时，会发生泄漏，可能会暴露用户的真实 IP 地址和 DNS 服务器使用情况。

hackernews · lapcat · 8月4日 23:31 · [社区讨论](https://news.ycombinator.com/item?id=49176697)

**背景**: WebKit 是苹果 Safari 和其他 iOS 和 iPadOS 浏览器中广泛使用的浏览器引擎。IP 和 DNS 泄漏发生在网络流量未能通过安全隧道正确路由时，从而暴露敏感用户数据。
